# Akshaya's 25th Birthday Celebration Web App ✨🎂

Welcome to the **akki** project workspace!

## 3-Page Celebration Journey
1. **Page 1 (`index.html`)** — **The Grand Beginning**:
   - Akshaya's full birthday portrait floating in a 16:9 laptop cinema frame.
   - Warm matching blurred ambient background with cascading fairy lights.
   - 20 Neon Gold flying butterflies with black outlines.
   - Interactive button: **"Unlock Your Surprise 🦋🥳"** (flies butterflies together and blasts into firecrackers before opening Page 2).

2. **Page 2 (`page2.html`)** — **The Golden Celebration**:
   - Starts pitch-black and slowly reveals radiant brightness.
   - 4 golden spotlights sweeping and focusing inward from all 4 corners.
   - Shimmering golden headline: **"HAPPY BIRTHDAY AKSHAYA"**.
   - Heartfelt quote: *"Happy Birthday! Never Stop Shining - The World Is better with your light in it."*
   - Glossy balloons floating smoothly from the bottom to the top of the screen (safely along the sides so they never cover the text).
   - Firecrackers blasting at random places in the sky with realistic acoustic pops and sparkles.
   - Floating golden button: **"Continue to Balloon Surprise 🎈"** leading to Page 3.

3. **Page 3 (`surprise.html`)** — **Pop All Balloons**:
   - Sized to fit comfortably on one single page.
   - Interactive 2x2 grid of 4 red balloons.
   - Tapping each balloon pops it with acoustic pop audio and a confetti explosion, revealing Akshaya's secret birthday wishes.
   - Grand finale celebration card when all 4 are popped!

---

## How to Run in Visual Studio Code

### Method 1: Local Server (Currently Live)
1. Run `node server.js` in the VS Code terminal.
2. Open **`http://localhost:3000`** in your browser!

### Method 2: Live Server Extension / Direct Open
- Right-click `index.html` -> **"Open with Live Server"**, or double-click `index.html` directly in your file explorer. All paths are relative and self-contained!
